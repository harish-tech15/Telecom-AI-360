# 📡 TelecomAI 360

AI-Powered Telecom Customer Churn Intelligence Platform.

## Features

1. TelecomBot AI – FAQ chatbot
2. AutoPrep AI – Automated data analysis
3. ChurnPredict AI – ANN-based churn prediction
4. Analytics Dashboard – Model performance metrics

## Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- TensorFlow / Keras
- Streamlit

## Dataset

IBM Telco Customer Churn Dataset.

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
